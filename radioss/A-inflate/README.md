# OpenRadioss — letter A inflate first light

SI deck for Inflation ABC letter **A** (`meshes/A.json`, N=1554).
Physics first: **same μ**, **ρ = 1130 kg/m³**, kiss gap tied to H0. Not MONVOL.

Deck is **quad-only** (`/SHELL` only — no `/SH3N`) and **free-free** (no `/BCS` 3-2-1 pins).

## Quad-only

Ship `meshes/A.json` is 1540 quads + 28 orphan **cap** `faceTris` (`nMidTris=0`). Converter **pairs** those orphans along shared edges into 14 `/SHELL` quads. Midplane is **not** remeshed to triangles. Inflate part has **no `/SH3N`**.

## Inertial relief / free-free

3-2-1 `/BCS` pins are **off**. OpenRadioss explicit analogue of inertial relief:

| Keyword | Where | Role |
|---------|-------|------|
| **`/ADYREL`** | engine | adaptive dynamic relaxation (documented free-free / IR analogue) |
| **`/DAMP`** | starter | Rayleigh mass α=80 1/s (kept) |

Radioss has **no `PARAM,INREL`** (OptiStruct). Closed `/PLOAD` is self-equilibrated.

## Run (cloud)

```bash
bash radioss/install_openradioss.sh
python3 tools/mesh_to_radioss.py --check
bash radioss/A-inflate/run.sh
```

Install pulls GitHub release `OpenRadioss_linux64.zip` (gfortran linux64: `starter_linux64_gf`, `engine_linux64_gf`, `anim_to_vtk_linux64_gf`) into `radioss/opt/` (gitignored). See `RUN.md` for the job that actually ran.

## Post

`tools/radioss_post.py` converts ANIM → VTK, reports λ_max(t), V(t), p(t), Ψ(t)≥0, writes GIF/MP4 with the first λ≥2 frame labeled. Frames are **quad fills + perimeter edges** (no CST diagonal bleed).
